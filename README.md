# Biopulse

Мобильная 2D ЭМГ-игра. Основное ТЗ: [PROJECT_SPEC.md](PROJECT_SPEC.md), редакция 1.1.
Unity: **6000.6.4f1**. Готовы тракт ввода, физическая сцена, Р-прыжок и С-захват с отпусканием по Р.

## Тестовая сцена движения

В начале сцены есть **синий терминал**: персонаж остановится у него.
Отпустить F/R, затем удерживать **F+R минимум 0.5 с**, наблюдая прогресс замка.
Нажатия могут идти последовательно: точное совпадение не требуется, можно сначала
зажать любую клавишу и добавить вторую. Таймер идёт только при двух активных каналах.
Прерывание уже начавшегося совместного удержания сбрасывает попытку и требует покоя.
После открытия отпустить обе клавиши:
персонаж продолжит бег, ворота исчезнут, терминал станет зелёным. R/F по отдельности
у терминала не вызывают прыжок/захват. Reset position снова закрывает ворота.

Открыть **Biopulse → Scenes → Open Movement Test** или `Assets/Scenes/MovementTest.unity`.
Нажать **Play**. Персонаж падает на платформу, автоматически бежит вправо со скоростью
4 ед/с. На пути три препятствия высотой 0.8 / 1.6 / 2.4; в конце — розовая преграда 2.6.
Финальная преграда проверена при амплитуде Р=1, включая прыжок вплотную к ней.
Камера следует за ним. Клавиша **R** (канал Р) запускает прыжок с силой от амплитуды.
Для сравнения поставить амплитуду Р 0.35 / 0.60 / 0.90 и прыгать с одинакового места.
Удержание не повторяет прыжки: перед следующим действием отпустить каналы.
**F (С)** вытягивает руку к жёлтой цели; амплитуда определяет максимальную дальность.
Захват автоматический, если цель достижима и не закрыта стеной. Отпусти клавиши:
покой сохраняет захват без сокращения. **R в захвате отпускает**, без прыжка/толчка.
Сначала попробуй С=0.9 перед первой жёлтой целью; можно также захватывать в воздухе.
Для повторной попытки отпустить оба канала. F+R вне терминала нейтрально. Повторного прыжка в воздухе нет.
Если упёрся в препятствие, можно прыгнуть с места либо нажать Reset position.
Панель показывает скорость, опору и блокировку. `Reset position` возвращает персонажа
на старт; выход за нижнюю границу стенда также возвращает на старт.

С/Р и их амплитуды видны в компактной панели; `Full input panel` открывает подробный
эмулятор. Панель также показывает фактические амплитуду, импульс, высоту и число прыжков.
`Run Speed`, `Min/Max Jump Impulse`, `Coyote Seconds` и `Jump Buffer Seconds` в компоненте
`RunnerMotor2D` на объекте Runner задаёт скорость. Для наблюдения свободного падения
с края можно временно отключить объект `Environment/Collision wall` в Play Mode.
После фактической потери фокуса/данных отпустить каналы и нажать `Resume input`:
физика персонажа возобновится с сохранённой вертикальной скоростью.

Персонаж — prefab `Assets/Biopulse/Prefabs/Runner.prefab`. Физика: Rigidbody2D,
CapsuleCollider2D, нулевое трение, непрерывные столкновения и замороженное вращение.
Это стенд с простыми формами; калибровка, обучение и полноценные уровни ещё впереди.

## Проверка ввода в Editor

1. Открыть проект в указанной версии Unity, дождаться импорта и компиляции.
2. Выбрать **Biopulse → Input → Open EMG Diagnostics**. Play Mode не требуется.
3. Установить независимые амплитуды С и Р (например, 0.35 / 0.60 / 0.90).
4. В фокусе окна удерживать **F** для С, **R** для Р, обе клавиши для С+Р.
   Мышью доступны кнопки `Hold С`, `Hold Р`, `Hold Both`.
5. Сравнить Raw и Processed, состояние и номер последнего намерения.
6. Удержание создаёт одно намерение. Для нового жеста отпустить оба канала.
7. `Simulate missing data` имитирует отсутствие кадров, `Simulate NaN` — плохое значение.
   После сбоя убрать имитацию, отпустить каналы и нажать **Resume after fault**.
   Потеря фокуса окна также требует продолжения.

Окно — служебный стенд, не пользовательское меню будущей игры.

## Runtime-адаптер для следующего этапа

`EmgInputDriver` можно добавить на GameObject тестовой сцены. Он использует новый Input System:
F/R, независимые амплитуды в диагностической панели, две touch-зоны с вертикальной
амплитудой и одновременными касаниями. Мышью можно удерживать одну зону; F+R позволяет
проверить оба канала. Ввод зависит от Game View, который должен иметь фокус.
После смены фокуса/фона отпустить каналы и нажать Resume.

`RunnerCommandRouter` подписывается на `IntentRecognized` и передаёт `GameCommand` в motor,
который не читает устройства.
Для замены источника используется `SetSource(IEmgSource, EmgCalibration)`.
Runtime-адаптер и touch пока не проверены на телефоне; APK не собран.

## Тесты

**Window → General → Test Runner → EditMode → Run All**.
Сборка тестов: `Biopulse.EditMode.Tests` (22 проверки). Во вкладке PlayMode доступна
`Biopulse.PlayMode.Tests` (проверки Unity-адаптера и физики персонажа).
Используются виртуальные метки времени;
тесты не доказывают задержку от touch до видимого движения персонажа.

## Ограничения этапа

- Профиль эмулятора 0..1 задан явно. Пошаговая калибровка и сохранение профилей — следующий этап.
- Replay принимает синтетическую последовательность в памяти; файловый формат/импорт ещё не реализованы.
- Для Raw-ЭМГ нужен процессор конкретного устройства. Сейчас поддерживается Envelope.
- Есть персонаж, Physics2D, router, пропорциональные Р-прыжок и дальность С-захвата,
  замок С+Р; обучение и пользовательские меню ещё не реализованы.
- Полный мобильный прогон и измерение задержки до экрана остаются обязательными.
- Клиническая эффективность и аппаратная совместимость не проверялись.
