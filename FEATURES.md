# Функции и применение ИИ

Этап 1, 3 ноября 2026. Код в `Assets/Biopulse` и сопроводительная документация
сгенерированы/изменены Codex по запросу команды. Человеческий автор/правообладатель
проекта определяется командой; этот документ не является передачей прав.

| Функция | Реализация | Проверка |
|---|---|---|
| IEmgSource, кадры и намерения | Есть | Автотесты, см. отчёт |
| Двухканальный эмулятор, амплитуды, С+Р | Есть | Core — автотесты; интерфейс — ручная проверка требуется |
| Replay в памяти | Есть | Сравнение 30/144 FPS в автотесте |
| Валидация, limiter, EMA, нормализация | Есть | Автотесты |
| Гистерезис, арбитраж, подтверждение, rearm | Есть | Автотесты |
| Блокировка и явное продолжение после сбоя | Есть | Core — автотесты; фон на телефоне не проверен |
| Editor-стенд, runtime Input System/touch | Есть | Компиляция, 3 PlayMode-теста драйвера; touch на устройстве не проверен |
| Персонаж, автобег, пол/стена, камера и MovementTest | Есть | PlayMode-проверки физики; ручной прогон человеком требуется |
| Р-прыжок с амплитудой, buffer/coyote, GameCommand/router | Есть | Автотесты физики и пути Replay → intent → command → motor |
| Проходимая финальная преграда 2.6 | Есть | Автотест перелёта реальных prefab при Р=1, включая старт вплотную |
| С-захват, пропорциональная дальность, покой и Р-отпускание | Есть | 6 новых PlayMode-тестов и прогон сохранённой сцены |
| Замок С+Р, остановка, покой, удержание, открытие ворот | Есть | EditMode FSM и PlayMode Replay через router/физику |
| Мобильный билд и полная задержка ≤100 мс | Нет | Не проверено |

Сторонние пакеты: Unity-пакеты и CoplayDev MCP for Unity указаны в manifest/lock.
Полный реестр лицензий и компонентов для сдачи ещё требуется подготовить.
